**Messages des Réminiscences Mystiques de l'Anthropologue :**

Lus à travers les lunettes colorées, les codes polychromatiques (et anaglyphes) donnent les mots suivants. *Ces images sont les mêmes dans les versions française et anglaise du jeu.*

- Message « Grimoire traceur » : GRIMOIRE TRACEUR (légende associée, en police gothique Fraktur : « serrure vortex abyssal »)
- Message « Domaine Interdit » : DOMAINE INTERDIT
- Message « Grimoire Chantant » : GRIMOIRE CHANTANT
- Message « Initiation Dynastique » : INITIATION DYNASTIQUE
- Message « Orbe Spirituel » : ORBE SPIRITUEL
- Message « Mort aux impurs », devant le tombeau du mage : MORT AUX IMPURS
- Message « Thanatologue » : THANATOLOGUE
